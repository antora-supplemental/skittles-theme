= Skittles Theme
:url-docs: https://antora-supplemental.github.io/skittles-theme

A high-vibrance, high-contrast Antora theme built on https://github.com/antora-supplemental/valentus-theme[Valentus Layout].
It has 11 color schemes, rainbow strips at the top and bottom of the page, a rainbow nav divider and rainbow TOC wires, all tested with axe for WCAG AA contrast.

{url-docs}[*Explore the docs »*]

== What's inside

[cols="1,3"]
|===
|Part |Role

|`packages/skittles-layout`
|Layout overlay that extends `@antora-supplemental/valentus-layout@4.2.1`. Adds `css/skittles-chrome.css` with geometry only (strips, divider, wires, border widths, motion) and no literal colors.

|`paint`
|Skittles Paint. One `css/skittles-paint.css` with the `@color-schemes` manifest and 11 generated `--sk-*` token blocks, linked at the Valentus paint slot.

|`docs`
|Docs component, with a brand overlay holding the skittle header mark (docs-only).
|===

== Schemes

Strawberry, Orange, Lemon, Green and Grape each come in light and dark, plus *Grape Soda*, a bright purple special scheme.
Light and dark schemes are slot candidates: choosing one fills that slot, and automatic light/dark switching stays on.
Only Grape Soda (slot none) turns the automation off.

== Quick start

[source,bash]
----
pnpm install
pnpm paint:validate   # strict validate-paint + manifest checks
pnpm test             # node --test: slots, contrast, overlay links, no logo files
pnpm build            # Antora site to build/site
pnpm test:a11y        # contrast-check: 5 pages x every scheme, light + dark (run after pnpm build)
----

Release bundles (`ui-bundle.zip` with paint baked in, and the layout-only `skittles-layout-bundle.zip`) are built by `.github/workflows/release.yml` via `scripts/build-bundle.mjs`.
